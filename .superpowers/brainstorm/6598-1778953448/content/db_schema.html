Проектирование базы данных

Схема таблиц и связей

Таблицы SQLite (SQLAlchemy)
lines
  id (PK), name, description

robots
  id (PK), line_id (FK), name, model, type,
  has_gripper, has_torch, ...

sensors
  id (PK), robot_id (FK), label, type, unit,
  normal_min, normal_max

notifications
  id (PK), type (critical/warning), robot_name,
  line_name, message, timestamp

Логика сопоставления

Каждый Robot в БД будет иметь поле ros_topic_prefix (например, /arm). Бэк будет слушать эти топики и отдавать данные в API, обогащая их информацией о порогах из таблицы sensors.
