# Детальное описание конструкции и материалов

В данном разделе описывается теоретический выбор компонентов для физического прототипа, который мы симулируем.

## 1. Конструкционные материалы
- **Основные звенья:** Анодированный алюминиевый профиль 20x20 мм. 
  - *Почему:* Высокое отношение прочности к весу, простота монтажа.
- **Узлы вращения:** Подшипниковые узлы с 3D-печатными корпусами из PETG пластика.
  - *Почему:* PETG обладает достаточной ударной вязкостью и химической стойкостью по сравнению с PLA.
- **Щуп (захват):** Комбинация ABS-пластика и силиконовых накладок на концы для обеспечения трения при захвате.

## 2. Электроприводы
- **Основание (Axis 1):** Шаговый двигатель NEMA 23 с планетарным редуктором 1:10.
  - *Почему:* Высокий удерживающий момент, необходимый для поворота всей конструкции.
- **Локоть (Axis 2):** Мощный сервопривод (например, RDS3115) или NEMA 17.
  - *Почему:* Необходима высокая точность позиционирования и встроенная обратная связь.

## 3. Электроника
- **Главная плата:** STM32F407 (Discovery или аналоги).
  - *Почему:* Наличие аппаратного FPU для быстрых расчетов кинематики и большое количество ШИМ-выходов.
- **Драйверы:** TMC2209 для шаговых двигателей.
  - *Почему:* Бесшумная работа и поддержка технологии StallGuard для определения упора без концевиков.
