# RoboArm: Курсовой проект по дисциплине «Микропроцессорная техника»

Курсовой проект посвящен разработке, симуляции и созданию системы управления для двухосевого промышленного манипулятора (роборуки). Проект охватывает полный цикл разработки: от физической симуляции в Webots до создания кроссплатформенного мобильного приложения для мониторинга и управления.

---

## 🏗 Архитектура системы

Проект разделен на три ключевых контура, взаимодействующих по сети:

1.  **Контур симуляции (Webots):**
    *   Физическая модель роборуки с двумя активными шарнирами.
    *   Низкоуровневый контроллер на языке **C**, симулирующий работу МК STM32.
    *   Интеграция с **micro-ROS** для передачи телеметрии и приема команд по UDP.

2.  **Контур управления (ROS 2 & Backend):**
    *   **ROS 2 Humble:** Центральный узел обработки данных.
    *   **PID-регуляторы:** Плавное управление движением осей.
    *   **FastAPI Bridge:** Сервер на Python, выступающий шлюзом между ROS 2 и веб-клиентами. Хранит конфигурацию и историю в **SQLite**.

3.  **Контур мониторинга (Mobile App):**
    *   Приложение на **Kotlin (Jetpack Compose)**.
    *   Архитектура **MVI** для надежного управления состоянием.
    *   Визуализация телеметрии датчиков в реальном времени.

## 📁 Структура репозитория

*   [`simulation/`](./simulation) — Мир Webots, PROTO-файлы и исходный код C-контроллера.

*   [`microros_ws/`](./microros_ws) — Ворксплейс ROS 2 с кастомными сообщениями и нодами управления.

## 🦾 Технические характеристики манипулятора

Симулируемый прототип основан на следующих компонентах:
-   **МК:** STM32F407 (эмулируется C-контроллером).
-   **Приводы:** NEMA 23 (основание) и NEMA 17 (локоть).
-   **Датчики:** Магнитные энкодеры (положение) и датчики тока (усилие).
-   **Протокол связи:** micro-ROS (XRCE-DDS) через UDP.

## 🚀 Быстрый запуск

### 1. Подготовка окружения
Убедитесь, что у вас установлен Docker и Webots.

### 2. Запуск ROS 2 и Агента
```bash
# Сборка и запуск контейнера с ROS 2
docker-compose up -d
```

### 3. Запуск симуляции
Откройте файл `simulation/worlds/robotic_arm.wbt` в Webots. Убедитесь, что контроллер успешно подключился к micro-ROS агенту.

### 4. Запуск бэкенда
```bash
export PYTHONPATH=$PYTHONPATH:.
python3 backend/web_bridge.py
```

### 5. Мобильное приложение
Откройте `mobile/android` в Android Studio, дождитесь синхронизации Gradle и запустите проект на эмуляторе.
